Trên macOS, `Ctrl` trong bảng là `Cmd`. Phím tắt bị vô hiệu khi bạn đang gõ chữ hoặc khi có menu hay hộp thoại mở.

## Chung

| Phím | Tác dụng |
|---|---|
| `Ctrl+N`, `Ctrl+O`, `Ctrl+S` | Dự án mới, mở, lưu |
| `Ctrl+Shift+S` | Lưu bản sao có ngày giờ |
| `Ctrl+Z` | Hoàn tác (60 bước) |
| `Ctrl+Shift+Z` hoặc `Ctrl+Y` | Làm lại |
| `Tab` | Bật hoặc tắt chế độ Show |
| `F11` | Mở hoặc đóng cửa sổ output |
| `Esc` | Đóng menu, hộp thoại, Cài đặt |

## Trang Composition

| Phím | Tác dụng |
|---|---|
| `Space` | Phát hoặc tạm dừng |
| `Enter` | Phát clip đang chọn |
| `←`, `→` | Cột trước, cột sau |
| `L` | Đặt clip đang chọn về chế độ LOOP |
| `Delete`, `Backspace` | Xoá clip đang chọn |

## Trang Advanced Mapping

| Phím | Tác dụng |
|---|---|
| `Ctrl+C`, `Ctrl+X`, `Ctrl+V` | Copy, cắt, dán |
| `Ctrl+D` | Nhân đôi |
| `Delete` | Xoá phần tử đang chọn |
| Mũi tên | Dịch 1 px; thêm `Shift` để dịch 10 px |
| `Ctrl` hoặc `Shift` và bấm | Chọn nhiều |
| Lăn chuột | Zoom theo con trỏ |

## Cửa sổ output

Khi cửa sổ output đang được chọn, `Esc`, `F11` hoặc `Ctrl+W` (`Cmd+W`) đóng nó.
